# itzy phone

以台灣中文製作的非官方 ITZY 手機模擬遊戲，體驗身為五位成員共同好友的日常互動。

[開始遊玩](https://xing5740.github.io/itzysmartphone/)

首次遊玩可設定 Instagram ID 和稱呼，透過 KakaoTalk 聊天、分享照片，體驗 Instagram 貼文、限時動態與私訊互動。

進度自動儲存在目前的瀏覽器，可在遊戲「設定」中重新開始。

## 本機執行

```sh
npm run dev
```

開啟 http://127.0.0.1:4173 。

對話與互動設定在 `js/config.js`，圖片放在 `photo/`。

## 聲明

- 本作為非官方同人遊戲，人物互動與對話皆為虛構。
- 照片素材皆來自 ITZY 官方和成員帳號。
- 部分對話與互動使用 AI 生成。
